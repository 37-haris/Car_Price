Documentation API

Routes / paramètres / codes / erreurs (précis et suffisant pour soutenance).

Accueil Concessionnaires Admin

0) Accès & rôles

  • admin : accès total (admin + concessionnaires + documentation)
  • user : accès concessionnaires uniquement si is_approved = true

Authentification (Web)

  • GET /login : page de connexion
  • POST /login : envoi email/password → création d’une session
  • GET /logout : déconnexion (suppression session)
  • GET /register : page création compte
  • POST /register : création compte (statut “en attente”)

1) Prédiction véhicule

POST /api/predict
Auth requise : login_required (session) + compte approuvé
Body JSON (features clés)
{
  "brand": "Peugeot",
  "model": "208",
  "fuel": "diesel",
  "gearbox": "manual",
  "year": 2019,
  "mileage_km": 82000,

  "doors": 5,
  "seats": 5,
  "power_hp": 100
}
Réponse 200 (OK)
{ "predicted_price_eur": 9450 }
Erreurs possibles
  • 401 : non connecté (pas de session)
  • 403 : compte non approuvé (en attente validation admin)
  • 422 : payload invalide / champs manquants
  • 500 : erreur serveur (exception)

2) Analyse marché – série (évolution)

GET /api/market/price-series?marque=Peugeot&annee=2019&carburant=diesel
Auth requise : login_required
Paramètres requis
  • marque (string)
  • annee (string/int)
  • carburant (string)
Réponse 200 (OK)
{
  "filters": { "marque": "Peugeot", "annee": "2019", "carburant": "diesel" },
  "x": ["Jan", "Feb", "Mar", "Apr", "May", "Jun"],
  "y": [12000, 11800, 12100, 12500, 12300, 12700]
}
Erreurs possibles
  • 401 : non connecté
  • 403 : compte non approuvé
  • 422 : paramètres manquants
  • 500 : erreur serveur

3) Analyse marché – plus grande évolution annuelle

GET /api/market/top-change?marque=Peugeot&carburant=diesel
Auth requise : login_required
Paramètres requis
